# Functional Gas Stove

![Functional Gas Stove Preview](https://github.com/PaffcioStudio/Functional-Gas-Stove/blob/main/image/preview.png?raw=true)

**Functional Gas Stove** turns the vanilla gas ranges found in houses into usable cooking workstations. It reuses the game's existing stove models and Campfire-style cooking interface, while using the **Gas Can** as fuel.

### 🌟 Features
* **Vanilla Integration:** Existing White, Grey, and Black Gas Range blocks become fully functional cooking stations.
* **Efficient Fuel:** Uses the **Gas Can** as the fuel source. A single Gas Can lasts for exactly **5 minutes**, making it vastly superior to Coal, which burns out after just 1 minute and 40 seconds.
* **Full Tool Support:** Fully compatible with the Cooking Pot, Cooking Grill, and Beaker.
* **Campfire Recipes:** All standard campfire cooking recipes are available to use.
* **Portability:** Gas stoves can be easily picked up and relocated to your base.
* **Craftable:** Includes a recipe to craft your own gas stove from scratch.
* **UI Consistency:** Version 1.0.4 adds the exact same recipe category tabs used by the vanilla Campfire.

### ⚠️ Requirements
* **7 Days to Die V3.2.x**
* **0_TFP_Harmony**
* **Easy Anti-Cheat (EAC) disabled**

### 🌐 Multiplayer
Because version 1.0.4 contains a custom Harmony DLL for the recipe-category UI, you must install this mod on both the **dedicated server** and **every connecting client**.
